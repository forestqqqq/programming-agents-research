# agents/ — 单个智能体的研究笔记

每个被研究的智能体一个子目录，例如 `agents/pi/`。

## 每个目录的建议文件

| 文件 | 内容 |
|---|---|
| `overview.md` | 项目概况：定位、仓库地址、研究的 commit/版本、 star/维护状况 |
| `architecture.md` | 架构分析：模块划分、核心流程、关键数据结构 |
| `notes.md` | 阅读笔记：按阅读顺序记录，含源码文件/行号引用 |
| `mechanisms.md` | 值得写进书的机制亮点（可选） |

> 笔记里引用源码时写明文件路径与行号（如 `src/loop.ts:120`），并注明所基于的 commit，方便日后对照新版。
> 摘录源码片段时注意长度与版权，公开仓库中以**自己的分析表述**为主。
